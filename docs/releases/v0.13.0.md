## English

- Added Antigravity messages and task-state integration with a separate purple AG bubble. Codex, DSH, and Antigravity bubbles can appear together; each opens its matching application when clicked.
- Added a “Show Antigravity messages” switch and updated the Chinese, English, and Japanese interface text.
- Reads Antigravity's local status database and public reply transcript in read-only mode. Filesystem changes and application-exit events drive updates. No Hook, extra plugin, or runtime is required; internal reasoning, system messages, and tool results are not displayed.
- Active Antigravity tasks have no fixed timeout. Completion and interruption reactions settle automatically, and historical completions are not replayed at startup.
- Improved multiple-bubble positioning to avoid overlaps near display edges.
- Updated the app icon to Gugu's head, collar, and metal pendant. Packages include a content-addressed ICO, and desktop-shortcut updates refresh Windows' icon cache.
- Included the legacy-watcher cleanup fix. Updates remove obsolete launch watchers from historical and rollback folders and keep the fixed launcher aligned with the current pet.

Download `GuguPet-Windows-x64-v0.13.0.zip`, extract it, and run `GuguPet.exe`. The self-contained Windows x64 portable build requires no separate .NET installation. Existing users can also upgrade with “Check for updates now” in the panel. The ZIP's SHA-256 is provided in `SHA256SUMS-v0.13.0.txt`.
