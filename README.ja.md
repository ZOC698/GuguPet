# 咕嘎（グーガー）デスクトップペット

[简体中文](README.md) | [English](README.en.md) | **日本語**

既存の Codex Pet v2 咕嘎（グーガー）スプライトシートを使用した、Windows ネイティブの WPF デスクトップペットです。Codex 本体や元の Pet ファイルは変更しません。

![咕嘎のアイコン](Assets/gugu-icon.png)

> 非公式のファンメイドプロジェクトです。OpenAI、Codex、bilibili、およびキャラクターの原作者とは提携しておらず、公式な承認も受けていません。

## ダウンロードと起動

リポジトリの **Releases** ページから `GuguPet-Windows-x64-*.zip` をダウンロードし、展開して `GuguPet.exe` を実行してください。現在のポータブル版は Windows x64 向けの自己完結型ビルドのため、.NET を別途インストールする必要はありません。

現在のリリースには Authenticode 署名がありません。初回起動時に Windows SmartScreen の警告が表示される場合があります。本リポジトリからのみダウンロードし、Release に掲載された SHA-256 を確認してください。

## 主な動作

- 待機アニメーション
- マウスホバーでジャンプ
- 左ボタンでドラッグ中に左右へ走る
- 初回起動時に手を振る
- 咕嘎の起動時に約 5 秒間の魚眼レンズ風登場演出を再生：待機、箱を押す、スーツケースによじ登る、レンズへ近づく、まばたき。コントロールパネルで無効化・プレビューでき、Esc キーでスキップ可能
- 既定では起動時に咕嘎だけを表示し、コントロールパネルは開きません。登場アニメーション設定からパネルの同時表示を再度有効にできます
- マウスを 16 方向へ追視
- ウィンドウ内座標とモニターごとの DPI 変換により、拡大率の異なるマルチモニター環境でも正確に追視
- `running`、`waiting`、`failed`、`review` などの Codex 状態アニメーション
- マウス追視は優先度の低い待機リアクションとして動作し、調整可能な時間後に待機状態へ戻る
- 既定で `%USERPROFILE%\.codex\sessions` を読み取り専用で監視し、Codex の開始・完了・エラーイベントに自動反応
- 公開 `agent_message` イベントから安全な進捗要約を取得し、咕嘎の横に一時的な吹き出しで表示
- コントロールパネルに直近 8 件の Codex タスクの状態、タイトル、公開進捗を表示。内部推論は読み取りも表示もしません
- リアルタイム進捗の吹き出しをクリックすると Codex ウィンドウを復元して前面に表示。Codex が未起動の場合はスタートメニューからの起動を試行
- 右クリックで即時コントロールパネルを表示
- サイズ、透明度、移動速度、常に手前に表示、動きを減らす設定
- ギター演奏、クッキーを食べる、3 種類の寝姿、入力待ち、水を飲む、伸び、座って考える、頭なで、腹部を守る専用リアクション
- コントロールパネルで追加動作を即時プレビューし、待機中のランダム再生間隔を設定可能
- デスクトップの作業領域内でランダムな目的地を選んで歩行。オン／オフと移動速度を調整可能
- 作業中は頬杖 50%、渦巻き目 30%、星目 20% の重みでランダムに切り替え、各フレームの大きさと位置を安定して維持
- 入力が必要な場合は、手を振る動作または「フリッパーを上げる → 身を乗り出す → 軽く叩く → 待つ」をランダム再生。完了時は星目、ジャンプ、クッキーのいずれかでお祝い
- 長時間の処理中は一時的に頬杖、水分補給、伸びを行ってから思考を再開。新しい進捗を受け取ると顔を上げて反応してから戻る
- 頭をクリックすると頭なで、腹部をダブルクリックすると腹部を守るリアクション。ドラッグを離すと減衰する慣性が働く
- コントロールパネルのクッキーを咕嘎へドラッグ可能。ポインターが足元へ近づくと、咕嘎が下を向いて観察
- 長時間操作がない場合、横向き、うつ伏せ、仰向けのいずれかでランダムに就寝。高速なマウス追跡は既定で無効、個別に有効化可能
- 任意の画面端アクション：端まで歩く、顔をのぞかせる、寝そべる、作業領域へ戻る
- ファイルを咕嘎へドロップするとローカルのファイル受け渡しデータをコピーして Codex を開き、入力欄への貼り付けを吹き出しで案内
- 状態吹き出しに入力待ち・失敗対応ボタン、完了要約、最大 8 件のタスク優先順位、左右切り替えを搭載
- 右クリックメニューの「新しい Codex タスク」の下に、直近 3 件のメインタスクと状態を表示。クリックで Codex に戻れますが、現在の公開インターフェースでは特定タスクへの直接リンクはできません

## 状態ブリッジ

コントロールパネルの「Codex の作業状態を自動追跡」は既定で有効です。Codex がタスクを開始すると `running`、入力を求めると `waiting`、完了後は一時的に `review`、明示的なエラーでは `failed` に切り替わります。この機能はセッションログを読み取り専用で参照し、Codex のデータを変更せず、内部推論の読み取りや表示も行いません。

「システム連携」にある「Codex と一緒に咕嘎を起動（Hook 不要）」は既定で無効です。ユーザーが有効にすると、通常のユーザー単位 Windows スタートアップ項目を登録し、非表示の監視モードで `ChatGPT.exe` を待機します。Codex デスクトップアプリの起動を検出すると咕嘎を表示します。無効にするとスタートアップ項目を削除して監視を停止します。`hooks.json` の編集や Codex CLI でのコマンド信頼操作は不要です。

## 言語パック

ポータブル版は初回起動時に `.NET CurrentUICulture` から Windows の表示言語を取得し、完全な地域コード、続いて言語コードの順に照合します。内蔵言語：

- `Locales/zh-CN.json`：簡体字中国語
- `Locales/en-US.json`：英語
- `Locales/ja-JP.json`：日本語

一致しない言語は英語へフォールバックします。「システム連携 → 言語」で自動選択を上書きでき、咕嘎を再起動すると反映されます。

新しい言語の追加にコード変更は不要です。任意の JSON ファイルをコピーし、`culture`、`displayName`、`strings` を編集して、`ko-KR.json` のような標準地域コードをファイル名に使用してください。中国語以外の言語パックで不足しているキーは英語、次に元の中国語文字列へフォールバックします。各言語パックの上限は 2 MB で、不正な形式のファイルは安全に無視されます。

ほかのローカルプログラムから制御する場合は、`%LOCALAPPDATA%\GuguPet\bridge-state.json` を編集できます：

```json
{
  "state": "running",
  "message": "タスクを処理しています"
}
```

対応状態：`idle`、`running-right`、`running-left`、`waving`、`jumping`、`failed`、`waiting`、`running`、`review`。

保存後すぐに変更が反映されます。任意のローカルスクリプトからこのファイルへ書き込むことでデスクトップペットを制御できます。
